# RiceLayer - project overview

Browser-extension prototype that applies CSS themes with validation and rollback paths.

**Stack:** TypeScript, React, Chrome Manifest V3, Express, Gemini integration.

**Status:** Public source. No Chrome Web Store release or adoption metric is asserted by this overview.

## Review this project

1. Read the root README for architecture and setup.
2. Inspect the implementation and tests, including external-service boundaries.
3. Run the repository's checks in a configured development environment:

```bash
npm run lint
npm test
npm run build
npm run smoke
```

These are verification commands, not a claim that every check has passed on the current commit.

## Boundaries

Theme safety is a design objective, not a guarantee across every website. External theme generation requires a configured backend.

This is personal project work developed with AI assistance. No paid-client history, commercial adoption or award is implied.
